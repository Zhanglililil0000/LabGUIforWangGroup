## 项目概述

本系统是一个基于 Web 的实验控制平台，用于控制 **SFG（和频振动光谱）** 和 **SRS（受激拉曼散射）** 光谱实验。系统通过 FastAPI 后端与硬件设备通信，前端提供直观的可视化操作界面。

```
浏览器 ──► FastAPI (REST + WebSocket) ──► 设备驱动 ──► 硬件仪器
```

### 支持设备

| 设备 | 用途 | SFG | SRS | 标定 |
|------|------|:----:|:----:|:----:|
| 光谱仪 (LightField) | 光谱采集 | ✓ | ✓ | ✓ |
| VIS 旋转台 | 可见光偏振 | ✓ | | ✓ |
| SFG 旋转台 | SFG 信号偏振 | ✓ | | ✓ |
| Raman 旋转台 | Pump (532nm) 偏振 | | ✓ | ✓ |
| 延迟线 | 时间延迟 | ✓ | ✓ | |
| 功率计 | 测量光功率 | | | ✓ |
| 距离传感器 | 样品高度测量 | | | ✓ |
| 垂直位移台 | 样品对焦 | | | ✓ |

## 启动系统

### 前提条件

1. Python 3.9+ 已安装
2. Thorlabs Kinesis 已安装（旋转台驱动）
3. LightField 软件已启动并加载实验预设（如需使用光谱仪）

### 启动命令

```powershell
cd d:\TraeProject\Project4SFG操作系统\CommandMode
python -m web.app
```

浏览器打开：**http://localhost:8080**

> ```python
> def run(host: str = "0.0.0.0", port: int = 8080):
> ```

## SFG 实验模式

### 光路原理

```
VIS (可见光)  +  IR (红外光)  ──►  SFG 信号
     ↕                              ↕
 VIS 旋转台                      SFG 旋转台
(偏振控制)                      (偏振控制)
```

### 偏振组合

| 模式 | VIS 角度 | SFG 角度 | 含义 |
|------|---------|---------|------|
| **SSP** | 45.58° (S) | 29.01° (S) | SFG-S, VIS-S, IR-P |
| **PPP** | 90.58° (P) | 74.01° (P) | SFG-P, VIS-P, IR-P |
| **SPS** | 45.58° (S) | 74.01° (P) | SFG-S, VIS-P, IR-S |
| **PSS** | 90.58° (P) | 29.01° (S) | SFG-P, VIS-S, IR-S |

### 可用步骤

`MotorHome`　`MotorMoveTo`　`DelayStageHome`　`DelayStageMoveTo`  
`SetExposure`　`SetWavelength`　`SetGrating`　`AcquireSpectrum`  
`SetPolarization`　`Sleep`　`LogMessage`

### 典型流程

1. 初始化 → VIS/SFG 电机归零
2. 设置波长 (475nm) 和曝光 (60000ms)
3. SSP 偏振 → 采集光谱
4. PPP 偏振 → 采集光谱

## SRS 实验模式

### 光路原理

```
Pump (532nm, 偏振可控)  +  Probe (超连续白光, 偏振固定)
        ↕                        │
   Raman 旋转台                   │
        └────────────┬────────────┘
                     ▼
                 光谱仪采集 → 帧间差分 → SRS 信号
```

### Pump 偏振

| 模式 | Raman 角度 | 含义 |
|------|-----------|------|
| **VV** | 42.47° | Pump 垂直, Probe 垂直 |
| **VH** | 87.47° | Pump 垂直, Probe 水平 |

### 数据处理

`AcquireSRSSpectrum` 步骤自动执行帧间差分算法：

```
ret1 = Σ(I[偶]/I[奇] - 1) / (N/2)
ret2 = Σ(I[奇]/I[偶] - 1) / (N/2)
ret  = (range(ret1) > range(ret2)) ? ret1 : ret2
```

输出文件：`{name}_ret.csv`（差分信号）、`{name}_ret1.csv`、`{name}_ret2.csv`

### 可用步骤

`MotorHome`　`MotorMoveTo`　`DelayStageHome`　`DelayStageMoveTo`  
`SetExposure`　`SetWavelength`　`SetGrating`  
`AcquireSpectrum`　`AcquireSRSSpectrum` (SRS 采集 + 差分)  
`Sleep`　`LogMessage`

### 参数独立性

`AcquireSpectrum` 和 `AcquireSRSSpectrum` 的 `exposure_ms` 参数**独立于** `SetExposure` 步骤——采集时自动应用自己的曝光时间，无需前置 `SetExposure`。

## 系统调试模式（标定）

系统调试模式不使用步骤编辑器，而是设置扫描参数后直接运行。扫描完成后显示图表并提供 CSV 下载。

### VIS 偏振标定

- **设备**: vis_rotator + power_meter
- **参数**: 起始角度 / 终止角度 / 步长 / 每步采样次数 / 功率计波长
- **流程**: vis_rotator 归零 → 按步长移动 → 每步多次测量功率取平均
- **输出**: 角度-功率 CSV 文件 + 折线图

### SFG 偏振标定

- **设备**: vis_rotator + sfg_rotator + spectrometer
- **参数**: VIS 固定角度 / SFG 起止角度 / 步长 / 曝光时间 / 波长
- **流程**: VIS 固定 P 偏振 → SFG 逐度扫描 → 每度采集一帧光谱
- **输出**: 角度-强度 CSV 文件 + 折线图

### 高度扫描

- **设备**: distance_sensor + spectrometer
- **参数**: 起始高度 / 终止高度 / 步长 / 曝光时间 / 高度误差阈值
- **流程**: 测量实际高度 → 根据距离反馈采集光谱
- **输出**: 高度-强度 CSV 文件 + 折线图

## 模板管理

### 工作原理

模板将当前的实验流程（采集组 + 步骤 + 参数）保存为 YAML 文件到 `configs/templates/{mode}/` 目录，方便重复使用。

### 操作方式

| 操作 | 步骤 |
|------|------|
| **加载模板** | 工具栏下拉框选择 → 自动加载（有 `{sample}` 占位符时弹窗输入样品名） |
| **保存模板** | 编辑好流程 → 点击 💾 → 输入模板名 → 确认（保存后下拉框自动选中） |
| **删除模板** | 下拉框选中 → 点击 🗑 → 二次确认 |

### 默认模板

系统预装了以下模板：

| 模式 | 模板 | 说明 |
|------|------|------|
| SFG | 默认模板 | SSP 偏振采集 |
| SRS | SRS 偏振扫描 | VV/VH Pump 偏振 |
| SRS | SRS 时间扫描 | 延迟线位置扫描 |
| SRS | SRS 波长扫描 | Stokes 区域波长扫描 |

### 模板文件位置

模板保存为 YAML 文件，可直接查看和手动编辑：

```
configs/templates/
├── sfg/
│   ├── sfg_ssp_ppp.yaml          ← 默认模板
│   └── my_custom_template.yaml   ← 用户保存的模板
├── srs/
│   ├── srs_pol_scan.yaml
│   ├── srs_time_scan.yaml
│   └── srs_wavelength_scan.yaml
└── calibration/
    ├── height_scan.yaml
    ├── sfg_pol_calibration.yaml
    └── vis_pol_calibration.yaml
```

## 运行实验

### 操作步骤

1. **选择模式** — 点击 SFG / SRS / 系统调试 标签
2. **连接设备** — 点击左栏「全部连接」（绿色圆点 = 已连接）
3. **编辑流程** — SFG/SRS 模式：添加采集组和步骤；系统调试：设置扫描参数
4. **运行** — 点击 ▶ 运行
5. **监控** — 右栏查看实时进度和日志
6. **暂停/停止** — 点击相应按钮

### 运行状态面板

- **进度条** — 显示当前实验的整体进度百分比和当前步骤名
- **步骤列表** — 所有步骤的执行状态（⏳等待 / ▶执行中 / ✓完成 / ✗失败）
- **日志面板** — 实时显示 `[info]` `[warn]` `[error]` 三级日志

### 状态栏

底部状态栏显示：连接状态 · 当前模板名 · 预计耗时

## 故障排查

### 设备无法连接（灰色圆点）

1. 检查设备电源是否开启
2. 检查 USB/串口线是否松动
3. 检查 `configs/devices.yaml` 中序列号/COM 口是否正确
4. 尝试「全部断开」→「全部连接」

### 实验运行失败（红色步骤）

1. 检查所有设备是否已连接
2. 检查参数是否合理（角度范围、曝光时间等）
3. 确保 LightField 已启动并加载正确的实验预设
4. 查看日志面板中的具体错误信息

### 模板保存后不显示

1. **强制刷新**页面（Ctrl+Shift+R）清除缓存
2. 检查保存时是否输入了模板名
3. 检查 `configs/templates/` 目录下是否有新文件

### SRS 信号异常

1. 检查 Pump 和 Probe 光路是否对准
2. 检查 Pump 偏振角度是否准确（VV: 42.47°, VH: 87.47°）
3. 曝光时间是否合适（太短信号弱，太长饱和）
4. 帧数是否足够（建议 ≥ 10000）

### 页面显示异常

1. 强制刷新页面 (Ctrl+Shift+R)
2. 使用 Chrome 或 Edge 浏览器
3. 检查浏览器控制台是否有 JavaScript 错误

### 日志解读

```
[info]  实验已启动            ← 正常信息
[warn]  设备响应较慢            ← 警告
[error] 设备连接失败            ← 错误，需要处理
```

## IDE 模式 vs Web GUI 模式

| 特性 | Web GUI 模式 | IDE 模式 |
|------|-------------|---------|
| 适用场景 | 日常操作、快速实验 | 开发调试、批量自动化 |
| 学习曲线 | 几乎零代码 | 需要 Python 基础 |
| 实验编辑 | 下拉式编辑器 | 编写 Python 脚本 |
| 模板管理 | 一键保存/加载/删除 | 手动编辑 YAML |
| 实时监控 | 进度条 + 步骤状态 + 日志 | print 输出 |
| 数据类型 | 14 种预设步骤类型 | 全部（含高级自定义） |
| 启动命令 | `python -m web.app` | `python my_script.py` |

> 两者共享配置文件 (`configs/devices.yaml`, `configs/defaults.yaml`) 和设备驱动，可无缝切换。
